# TaoDBM 核心功能真人模拟用例矩阵（五维穷举）

生成规则：操作对象 × 操作方式 × 参数形态 × 顺序与组合 × 异常边界/环境状态；每条用例 = 真人操作流 + 预期结果核对。云端起真实数据库实例，全部按真人鼠标键盘路径触发。

## C1 连接管理
- 操作：新建连接、连接、断开、重连、删除连接
- 参数：合法地址/错误口令/不存在实例/特殊字符库名
- 异常：断连后执行查询——预期：明确报错不崩溃
- 核对：连接状态与实际可达性一致

## C2 库表操作
- 操作：建库、建表、改表、删表
- 参数：各支持类型字段；特殊字符表名；主键/索引/约束
- 核对：结构回读与操作一致

## C3 数据增删改查（准确性重点）
- 写入→读回逐字段核对（写什么读什么）；更新→读回；删除→计数核对
- 参数：空值/中文/特殊字符/超长文本/边界数值/批量多行
- 排序筛选：多列排序、组合筛选，与 SQL 对照结果一致

## C4 导入导出
- CSV/SQL 导出→重新导入→行数+内容校验值前后一致
- 参数：含逗号引号换行的字段、空表、大表

## C5 SQL 执行与错误处理
- 合法 SQL 核结果；非法 SQL 预期：报错准确、不崩溃、连接不失效
