# 01 · 需求与功能清单

## 1. 项目定位

TaoDBM 是一款面向开发者的 Windows 桌面数据库管理工具，对标 Navicat 的日常核心工作流，
采用 WinUI 3 + .NET 8 原生技术栈，视觉遵循 Ant Design 规范。

### 与 Navicat 的关系（如实说明）

Navicat 最新版（Premium 17）包含数十个模块（结构同步、数据传输、模型设计、报表、
计划任务、云端备份、审计等），**任何第三方工具都无法也不应一次性复刻其全部功能**。
TaoDBM 的策略是：先把高频核心工作流做扎实，再按优先路线图逐步扩展。

## 3. 非功能需求

- 启动即用：WindowsAppSDK 自包含发布，无需用户另装运行时
- 安全：密码不明文落盘；不做任何网络上报
- 安装体验：微信式单页安装（协议勾选 + 目录 + 组件勾选 + 立即安装）
- 可打包：一键批处理产出单一 MSI 安装包（微信式单页界面，out 自检仅 1 项）
- 图标：道·太极 + 数据库圆柱，区分度第一眼可见

## 4. 约束

- 仅支持 Windows x64
- 连接串附加参数透传给各官方驱动，不自行解析特殊方言
- Redis 默认扫 db0-db15、单次最多 500 键；Mongo find 单次最多 200 文档
