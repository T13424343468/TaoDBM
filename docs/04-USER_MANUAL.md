# 04 · 用户手册

## 1. 安装

双击 `TaoDBM-1.2.1-x64.msi`：

1. 勾选「我已阅读并同意许可协议」
2. 确认安装目录（可直接输入，不存在会自动创建）
3. 按需勾选：桌面快捷方式 / 开始菜单 / 加入系统 PATH
4. 点「立即安装」→「安装」→「完成」

MSI 安装包内含全部运行库，装完即用；也支持静默部署
`msiexec /i TaoDBM-1.2.1-x64.msi /qn`。

## 2. 建立第一个连接

1. 点右上角「＋ 新建连接」
2. 选数据库类型（MySQL / PostgreSQL / SQL Server / SQLite / Oracle / MongoDB / Redis）
3. 填主机、端口、账号密码（SQLite 只需填数据库文件路径）
4. Oracle：可点「从 tnsnames.ora 解析服务名」选择本机 `tnsnames.ora` 文件，从解析出的
   服务名列表里选中一条，主机 / 端口 / 服务名自动回填
5. 点「测试连接」确认成功，再点「保存」

密码保存在本机 `%APPDATA%\TaoDBM\connections.json`，经 Windows DPAPI 加密，
换电脑无法解密。

## 3. 浏览数据库对象

右键菜单（v1.4.2）：在左侧树上右键任一节点即可操作——

- 连接节点：展开连接 / 编辑连接 / **关闭连接** / 删除连接。关闭 = 断开该连接（含 SSH 隧道），
  连接配置保留，之后展开即重新连接；删除会先确认，删除后自动关闭该连接已打开的页签。
- 库节点：刷新 / 新建查询 / 查看数据 / 设计表 / 备份还原 / ER 图。
- 表（集合 / 键）节点：刷新 / 新建查询 / 查看数据 / 设计表 / 拟真数据。

分库展示（v1.4.2）：不同类型的库用各自最合理的展示方式——

- MySQL / PostgreSQL / SQL Server / SQLite / Oracle：表格网格，单击行可编辑 / 删除，分页浏览；
- Redis：键值视图。库节点「查看数据」打开键列表（键名 / 类型 / TTL / 大小），
  单击键进入详情页（类型 / TTL / 值），详情页可直接「删除此键」；也可用命令页执行
  KEYS / GET / TTL / DEL 等命令；
- MongoDB：JSON 文档列表（_id + 文档内容）。

- 左侧树点连接名左侧箭头展开 → 自动列出所有库
- 再点库左侧箭头 → 列出表（MongoDB 为集合，Redis 为键）
- 「刷新」按钮：重新加载当前选中层级
- Redis 选中某个键后，新建查询默认填 `GET 键名`

## 4. 执行 SQL / 查询

1. 选中库（或表）后点「新建查询」
2. 编辑器输入语句，支持多语句（分号分隔，字符串/注释里的分号不会误拆）
3. 按 **F5** 或 **Ctrl+Enter**，或点「▶ 执行」
4. 多条语句的结果按顺序全部展示；写语句显示受影响行数；错误只标记该条，不中断后续

MongoDB：选中集合后新建查询，输入 JSON 过滤器（如 `{ "age": { "$gt": 18 } }`）执行 find。
Redis：输入 `KEYS user:*`、`GET key`、`TTL key`、`DEL key` 等命令。

## 5. 浏览、编辑与导入导出数据

- 选中表/集合点「查看数据」：每页 200 行，「上一页/下一页」翻页
- **编辑数据**：单击结果中的任意一行，弹出编辑窗——改完点「保存」；点「删除该行」二次确认后删除；表必须有主键才允许编辑（防止误改整表）
- **新增行**：点「新增行」，只填需要的列（留空 = NULL），点「保存」
- **导入 CSV / JSON**：点「导入」选择文件，首行为表头（需与列名一致），自动分批插入并报告成功行数；
  JSON 支持对象数组（`[{"id":1,"name":"x"}]`）和行式 JSONL（每行一个对象），嵌套对象/数组
  会序列化为 JSON 文本后写入
- **查看结构**：点「结构」查看列名 / 类型 / 可空 / 主键
- 「导出 CSV」：UTF-8 带 BOM，Excel 双击打开不乱码
- 「导出 INSERT」：生成可回放的 INSERT 语句脚本

## 5.4 备份 / 还原

- 左侧树选中连接（或库、表）→ 顶部点「备份」→ 选数据库、选「备份到文件」或「从文件还原」
- **MySQL**：调用 `mysqldump` / `mysql`（需已安装 MySQL 客户端工具并加入 PATH；密码经
  环境变量传递，不进命令行）
- **PostgreSQL**：调用 `pg_dump` / `psql`，要求同上
- **SQL Server**：直接执行 T-SQL `BACKUP / RESTORE DATABASE`，注意磁盘路径是数据库服务器上的路径
- **SQLite**：直接复制 / 覆盖 `.db` 文件；还原前会二次确认

## 5.5 SQL 语法着色与表结构设计器

- **语法着色**：查询编辑器自动分色——关键字蓝色加粗、类型紫色、字符串橙色、注释灰色斜体、
  数字绿色、引号标识符青色，输入后即时生效，无需任何设置
- **可视化建表**：左侧树选中一个「库」→ 顶部点「设计表」→ 填表名、逐列填列名/类型，
  勾选主键、可空、自增 → 点「生成 SQL」预览 DDL → 点「执行」
- **可视化改表**：左侧树选中一个「表」或在表数据页点「设计表」→ 增/改/删列后生成
  ALTER 语句预览并执行（SQLite 不支持改列，会自动跳过并提示）

## 6. 查询历史、收藏与补全

- **Ctrl+Space**：在编辑器里补全 SQL 关键字和当前表的列名
- **历史**：查询模式下点「历史」，最近 300 条记录点选即可回填编辑器（保存在本机）
- **收藏**：把常用 SQL 写好后点「收藏」→ 填个名字 → 「保存当前 SQL」；之后随时点选「填入所选」，
  同名保存会覆盖旧内容，「删除所选」可清理
- **标签会话**：打开的查询标签（包括里面的 SQL）在关闭程序时自动记住，下次启动原样恢复；
  表数据浏览页不自动恢复，避免启动就连库

## 6.5 数据传输与结构同步

- 左侧树选中任意连接后，顶栏点「传输」：选源连接与源库、目标连接与目标库 → 「加载表列表」
  勾选要搬的表（默认全选）→ 「开始传输」
- **结构同步**（默认开）：目标表缺列自动补；目标表不存在时按源结构 + 目标方言自动建表；
  「对齐共有列类型」默认关闭，勾上会修改目标表列类型，请谨慎；SQLite 不支持改列会跳过并提示
- **传输数据**（默认开）：源表全量 SELECT，按 200 行/批写目标，每表报告写入行数；不清空目标表
- MongoDB / Redis 连接不参与传输，对话框里会提示

## 6.6 模型设计（ER 图）

- 左侧树选中连接后顶栏点「ER 图」→ 选连接与库 → 「生成 ER 图」
- 每张表渲染为一个框（主键列标 🔑），按命名约定自动连线：`user_id` / `userId` 连到
  `user`（或 `users`）表的 id 主键；自引用与无主键目标不连线
- 表框可直接拖拽排布，「重新布局」回到网格；「导出 PNG」出图，「保存布局 / 打开布局」
  把位置存成 .erjson 文件（最多取前 40 张表）

## 6.7 报表

- 执行查询或浏览表数据后，工具栏点「报表」：每列给出空值数、去重值数，
  数值列给最小 / 最大 / 平均，非数值列给出现最多的前 3 个值
- 点「导出 HTML 报表」生成独立静态页（Ant 风格），浏览器直接打开或存档

## 6.8 拟真测试数据

在表数据页点「拟真数据」（或左树右键表节点 →「拟真数据」）打开多表模式（v1.4.2）：

1. 窗口列出当前库的全部表，每个表独立填生成行数（1 – 100000，留空 = 不生成），
   打开时的当前表已预填 50；
2. 选项：跳过主键列（自增主键推荐勾选）／执行前先清空要生成的表（危险操作）；
3. 点「生成预览」——每个表给出行数与首行样例（按字段名与类型推断语义：姓名、手机号、
   邮箱、身份证、金额、状态、枚举……）；
4. 点「执行写入」——按外键 / 字段名关联的拓扑顺序逐表执行：被引用的表先写入，
   子表引用列自动取父表刚写入的值（或库中已有值），保证外键不悬空；
   数据分批（500 行/批）写入，进度条按总行数推进。

同一行数 + 同一随机种子，生成的数据完全一致（可复现）；不同种子则不同。

## 7. SSH 隧道## 7. SSH 隧道

内网数据库无法直连时：新建连接 → 勾选「通过 SSH 跳板机连接」→ 填跳板机地址、账号密码。
程序会自动建立隧道并复用，数据库地址填真实内网地址即可。

## 8. 常见问题

| 现象 | 处理 |
| --- | --- |
| 测试连接失败 | 先查主机/端口/账号；服务器防火墙与白名单 |
| SQL Server 报证书错误 | 本版默认 TrustServerCertificate，若仍失败在附加参数写 `Encrypt=false` |
| Oracle 连接 | 附加参数栏填服务名（如 orcl），或用「从 tnsnames.ora 解析服务名」自动回填；分页需 12c+ |
| SQL Server 树 | 表按 `schema.table`（如 dbo.users）展示，与 PostgreSQL 一致 |
| 树展开报错 | 点「刷新」重试；检查网络与权限 |
| 结果太多界面卡 | 超限自动截断，请用「查看数据」分页或加 WHERE |
| 密码修改不生效 | 编辑连接后必须点「保存」 |
