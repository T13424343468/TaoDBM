# 06 · 真机验证清单

> 按顺序勾选即可完整过一遍全部功能；任何一步失败，把界面提示或
> `D:\TaoDBMData\TaoDBM\crash.log`（D 盘不可用则在 `%LOCALAPPDATA%\TaoDBM`）的最新几行发开发者即可定位。

## 0. 装包自检

- [ ] 窗口标题与顶栏显示当前版本号（如 `TaoDBM v1.2.6`），
      与 MSI 文件名版本一致，说明装的是最新包
- [ ] 双击 `TaoDBM-x.x.x-x64.msi` 出微信式单页界面（协议勾选 + 目录 + 组件勾选）
- [ ] 安装完成桌面 / 开始菜单有快捷方式

## 1. 连接与对象浏览

- [ ] 新建连接（各引擎逐个：主机 / 端口 / 账号 / 密码 / SQLite 文件路径）→ 测试连接通过
- [ ] 左侧树：连接 → 库 → 表（MongoDB 集合 / Redis 键）逐级展开，右键刷新
- [ ] PostgreSQL / SQL Server 按 `schema.table` 展示多 schema
- [ ] 编辑连接、删除连接生效
- [ ] Oracle：连接对话框「从 tnsnames.ora 解析服务名」选中后自动回填

## 2. 查询与编辑

- [ ] 查询编辑器 SQL 着色（关键字 / 字符串 / 注释分色）、Ctrl+Space 补全
- [ ] 多语句一次执行（含字符串 / 注释内分号不误拆），多结果集 + 耗时
- [ ] F5 / Ctrl+Enter 执行；查询历史出现并可回填；常用 SQL 收藏 / 填入 / 删除
- [ ] 表数据分页浏览（200 行 / 页）；点行弹出编辑窗，改 / 删 / 新增行生效
- [ ] 无主键表拒绝编辑并提示

## 3. 导入导出

- [ ] CSV 导出（Excel 打开不乱码）与 INSERT 导出
- [ ] CSV 导入当前表（含引号 / 跨行值），报告成功行数
- [ ] JSON 导入（对象数组 / 行式 JSONL / 单对象）

## 4. 备份 / 传输 / 同步

- [ ] MySQL / PostgreSQL 备份生成 dump 文件（需本机有 mysqldump / pg_dump）
- [ ] 传输：源连接 → 目标连接选表搬运，逐表报告行数；目标缺列自动补、缺表自动建
- [ ] 结构同步只加列不删列（默认）

## 5. ER 图与报表

- [ ] 「ER 图」表框自动布局、主外键虚线连线、拖拽、导出 PNG、.erjson 保存 / 打开
- [ ] 「报表」逐列统计（空值 / 去重 / 极值均值 / Top 值），导出 HTML 可打开

## 6. 主题

- [ ] 首次启动即水墨主题：玄墨顶栏 + 宣纸底，界面无残留蓝色主色
- [ ] 左上角菜单「主题：天灰」→ 中调冷灰底、控件面亮于底、深蓝点缀，即时全窗口生效
- [ ] 左上角菜单「主题：墨夜」→ 近黑暖序底 + 宣纸白字 + 黛青点缀，界面无刺眼生黑
- [ ] 「主题：水墨」切回；三主题来回切换无残留色块
- [ ] 切主题后重启程序，主题保持上次选择

## 7. 稳定性

- [ ] 关闭重开：查询标签与 SQL 原样恢复（表数据页不自动恢复属正常设计）
- [ ] SSH 隧道连接内网库可用；密码加密保存，重启程序免输
- [ ] 异常路径：断网执行查询应有错误提示而非闪退；若有异常，
      发 `D:\TaoDBMData\TaoDBM\crash.log` 最新几行（D 盘不可用则在 `%LOCALAPPDATA%\TaoDBM`）
